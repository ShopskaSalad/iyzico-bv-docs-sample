# API Documentation - beta1.1

Welcome to the iyzico API Documentation version beta1.1. This documentation will help you integrate our payment solutions into your application.

## What's New in beta1.1

This version includes several enhancements and improvements over beta1.0:

- **Enhanced Authentication**: Improved security mechanisms and OAuth 2.0 support
- **Better Performance**: 2x increased rate limits and faster processing
- **Extended Features**: Longer authorization periods (14 days) and improved workflows
- **Enhanced Security**: Better fraud detection and improved encryption
- **Better Reliability**: Improved webhook delivery and error handling

# SFTP - beta1.1

SFTP (Secure File Transfer Protocol) integration for batch operations and reporting. Enhanced features in beta1.1.

## Overview

SFTP integration allows you to:

- Download transaction reports
- Upload batch payment files
- Retrieve settlement files
- Access historical data

## SFTP Access

### Connection Details

- **Host**: `sftp.iyzico.com`
- **Port**: `22`
- **Protocol**: `SFTP`
- **Authentication**: SSH Key or Username/Password

## New in beta1.1

- Enhanced SFTP security
- Improved file transfer reliability
- Better error handling
- Automated report generation
- Real-time sync capabilities

## File Formats

### Transaction Reports

CSV format with enhanced columns and data in beta1.1.

### Settlement Files

Settlement files with improved format and additional reconciliation data.

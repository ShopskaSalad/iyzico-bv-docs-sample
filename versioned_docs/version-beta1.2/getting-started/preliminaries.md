# Preliminaries - beta1.1

This section covers the preliminary information you need to know before integrating our API version beta1.1.

## What's New in beta1.1

This version includes enhanced features and improved documentation structure.

## Prerequisites

Before you begin, make sure you have:

- A valid API key and secret key for beta1.1
- Access to the API endpoints
- Understanding of RESTful APIs
- HTTPS enabled on your server

## Basic Concepts

### API Base URL

All API requests should be made to:
```
https://api.iyzico.com/v2/
```

### Request Format

All requests should:
- Use HTTPS protocol
- Send JSON data in the request body
- Include authentication headers
- Use UTF-8 encoding

## Getting Your Credentials

Contact our support team to get your API credentials for testing and production environments.

## Differences from beta1.0

- Enhanced authentication mechanisms
- Improved error handling
- Updated request/response formats
- New endpoint capabilities
